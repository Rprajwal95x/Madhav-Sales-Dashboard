# Madhav-Sales-Dashboard

📊 Madhav Ecommerce Sales Dashboard

A professional Power BI dashboard created to analyze sales performance, customer behavior, profit trends, payment methods,
and product categories for an e-commerce business.

📈 Dashboard Features
1. Sales Analysis
Amount by state
Monthly profit analysis
Quarterly performance analysis

2. Customer Analysis
Top customers by purchase amount
Customer spending patterns

3. Product Analysis
Quantity sold by category
Profit generated by sub-category

4. Payment Analysis
UPI transactions
Debit card transactions
Credit card transactions
Cash on Delivery (COD)
EMI transactions

5. Filters and Slicers
Quarter filter
State filter
